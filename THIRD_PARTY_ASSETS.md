# Third-party assets

The current game art, models, animation rigs, UI artwork, and procedural audio are generated by repository code and are original to Empires of Meridian. No external art, audio, font file, model, texture, map, or proprietary game data is checked into the repository.

Runtime libraries are installed from npm and recorded with exact versions in `package.json` and `pnpm-lock.yaml`. Their licenses must be reviewed from the lockfile dependency graph before a public release. Browser and operating-system fonts are referenced by generic CSS families and are not redistributed.
