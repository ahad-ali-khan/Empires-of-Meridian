# IP compliance

Create original names, factions, lore, visual language, audio, maps, icons, unit roles,
and UI composition. Never import proprietary game assets, extract data, trace a map,
or reproduce distinctive text, symbols, interface layouts, sounds, or faction identity.
Record provenance and license for every third-party asset, font, texture, model, sound,
and code sample; block unknown provenance.

References may inform high-level genre conventions only. When similarity is material or
licensing is uncertain, stop and request a legal/creative decision rather than guessing.
