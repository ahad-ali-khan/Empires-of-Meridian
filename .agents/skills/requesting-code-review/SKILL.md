# Requesting code review

Provide intent, invariants, changed areas, risk surface, tests/evidence, and focused
questions. Request an independent review for multiplayer authority, serialization,
pathfinding, asset ingestion, authentication, or moderation changes. Do not include
credentials, private URLs, or copy-pasted proprietary source in a review request.
