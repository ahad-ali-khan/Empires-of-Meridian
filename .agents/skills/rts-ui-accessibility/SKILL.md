# RTS UI accessibility

Every gameplay action has a discoverable keyboard path and visible focus. Support
rebindable hotkeys, conflict detection, non-color-only ownership/status cues, readable
HUD at supported scales, captions/text alternatives where applicable, and a reduced-
motion mode. Do not rely on hover, rapid animation, audio alone, or red/green alone.

Test menus, lobby, HUD, pause, error recovery, and match controls with keyboard-only
navigation and representative color/contrast modes. Preserve scene input precedence
so text entry and assistive flows never trigger world commands.
