# Three.js post-processing

Start with no post-processing. Add a single measured pass only where it preserves
clarity; bloom, grading, fog, and screen effects must be toggleable and respect
reduced-motion/accessibility settings. Keep compositor resize/disposal explicit and
never use an effect that obscures selectable units or team colors.
